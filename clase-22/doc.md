## Carpetas y archivos

-vite.config.js - Archivo de configuracion del servidor de vite
-package.json - Archivo de configuracion de npm (configuracion de nuestro proyecto en node.js)
-package-lock.json - Archivo de configuracion de npm extendido (tiene mas informacion de las dependencias) (configuracion de nuestro proyecto en node.js)
-index.html - la pagina donde se construira la aplicacion
-README.md - Archivo de documentacion (es una guia para el uso de la app)
-.gitignore - Archivo donde indicaremos a git que cosas debe ignorar 
-eslint.config.js - Archivo de configuracion (NO LO USAMOS)
-src - Carpeta donde estan los archivos de la app
-public - carpeta donde se guardan archivos estaticos (lo vemos mas adelante)
